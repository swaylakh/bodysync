# Archive: earlier stages

Not needed to understand or rerun the final BodySync; kept as a record of how the project got there.

| Folder | What it is |
|---|---|
| `early_stage/` | The first idea ("sync": do the signals move together?) and the first formula, built on an everyday wristband dataset without stress labels. Scripts, their result tables and figures 1–5. The scripts expect to sit in `src/` and need that dataset (see `DATASET_SOURCE_ZU-PWD.md`). |
| `early_report/` | The mid-term LaTeX report (`main.tex`), its tables and the progress report. |
| `slides/` | The weekly and progress decks before the final one. |
| `README_full_history.md` | The full technical log of every stage, including the numbers before the final push. |
